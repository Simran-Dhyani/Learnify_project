# 🚀 Learnify

Learnify is an AI-powered learning platform built with the MERN stack that transforms YouTube into a personalized learning workspace.

Watch educational videos, take notes, generate AI quizzes, manage watch history, and organize your learning—all in one place.


## 🌐 Live Demo

https://learnify-project-two.vercel.app

## ✨ Features

- 🔐 Secure JWT Authentication
- 🎥 Search & watch YouTube videos
- 📝 Create, edit & delete notes
- 🤖 AI-generated quizzes using Groq API
- 📚 Organized notes dashboard
- 📺 Automatic watch history
- 👤 Profile management & avatar upload
- 🎨 Responsive UI with GSAP & Framer Motion animations

## 🛠 Tech Stack
