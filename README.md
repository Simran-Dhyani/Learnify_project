# 🚀 Learnify

Learnify is a full-stack AI-powered learning platform built with the MERN stack that transforms YouTube into a personalized learning workspace.

Instead of switching between YouTube, note-taking apps, and quiz tools, Learnify lets users watch educational videos, create notes, generate AI-powered quizzes, manage watch history, and organize their learning—all from one application.

# ✨ Features

## 🔐 Authentication

- User Registration & Login
- JWT Authentication
- Access & Refresh Tokens
- Protected Routes
- Persistent Login Sessions
- Secure Cookie-based Authentication

---

## 🎥 YouTube Learning

- Search YouTube videos
- Watch videos inside the application
- Dedicated distraction-free learning page
- Responsive embedded video player

---

## 📝 Smart Notes

- Create notes while watching videos in TinyMCE Editor
- Edit existing notes
- Delete notes
- Notes stored securely for each user
- Notes organized per video

---

## 🤖 AI Quiz Generation

Generate quizzes directly from your notes using the **Groq API**.

Features include:

- Multiple-choice questions
- Instant knowledge checks
- AI-generated questions from saved notes
- Better revision experience

---

## 📚 My Notes Dashboard

- Automatically groups notes by video
- Displays note count
- Quick navigation to saved learning sessions
- Organized learning history

---

## 📺 Watch History

- Automatically stores watched videos
- Recently watched videos displayed first
- Click any video to reopen it instantly
